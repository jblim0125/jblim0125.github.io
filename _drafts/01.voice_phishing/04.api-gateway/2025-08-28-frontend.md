
# Spring Cloud Gateway 를 위한 UI 

1. 배경정보
    - backend 는 spring cloud gateway(webflux)
    - 인증은 keycloak 연동을 통하여 처리
    - 권한의 경우 ROLE_SYSTEM_MANAGER 정보 필요
      - 기존 개발되어 있는 app.js 파일 내용을 참고

2. Vue 를 이용한 개발
3. 화면 구성
   1. Home ( API Gateway 임을 나타내는 문구와 배경 ) + Login(keycloak 으로 redirect 됨)
   2. Main : 좌측에 메뉴바( 메뉴바에 메뉴 구성은 라우트 설정, 하단에 로그아웃 )
   3. Route : index.html, app.js파일 내용을 참고하여 작성
4. 백엔드 수정
   1. securityfilterchain 에 필요한 내용 설정
5. 빌드
   1. 필요한 경우 build.gradle.kts 내용 수정

1.	StripPrefix
{
  "name": "StripPrefix",
  "args": {
    "parts": "1"
  }
}

2.	PrefixPath (prefix)
{
  "name": "PrefixPath",
  "args": {
    "prefix": "/mypath"
  }
}

3.	AddRequestHeader (name, value)
{
  "name": "AddRequestHeader",
  "args": {
    "name": "X-Request-Foo",
    "value": "Bar"
  }
}

4.	AddResponseHeader (name, value, 선택적 override)
{
  "name": "AddResponseHeader",
  "args": {
    "name": "X-Response-Foo",
    "value": "Bar",
    "override": "true"
  }
}

5.	SetRequestHeader (name, value)
{
  "name": "SetRequestHeader",
  "args": {
    "name": "X-Request-Red",
    "value": "Blue"
  }
}

6.	SetResponseHeader (name, value)
{
  "name": "SetResponseHeader",
  "args": {
    "name": "X-Response-Red",
    "value": "Blue"
  }
}

7.	RemoveRequestHeader (name)
{
  "name": "RemoveRequestHeader",
  "args": {
    "name": "X-Request-Foo"
  }
}

8.	RemoveResponseHeader (name)
{
  "name": "RemoveResponseHeader",
  "args": {
    "name": "X-Response-Foo"
  }
}

9.	RewritePath (regexp, replacement)
{
  "name": "RewritePath",
  "args": {
    "regexp": "/foo/(?<segment>.*)",
    "replacement": "/${segment}"
  }
}
