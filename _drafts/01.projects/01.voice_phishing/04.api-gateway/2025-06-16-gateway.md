# API Gateway for Voice Phishing Portal

## Overview

이 문서는 보이스피싱 데이터 수집 및 공유 시스템의 API 게이트웨이 설계 및 구현에 대한
내용을 다룹니다. Spring Cloud Gateway를 사용하여 API 요청을 라우팅하고 필터링하며,
Keycloak을 통해 인증 및 권한 관리를 수행합니다.

## Dynamic Routing

```text
Client ─▶ Spring Cloud Gateway ─▶ RouteDefinitionLocator (Custom)
                           │
                           ├─▶ Memory Cache (Caffeine, Redis 등)
                           └─▶ Database (e.g., MySQL, PostgreSQL)
```
