# MinIO 파일 저장 규칙

## 개요

보이스피싱 데이터 중 첨부데이터를 저장하기 위한 저장 규칙에 대해서 정의한다.

## 파일 이름 규칙

파일 이름은 중복을 피하기 위해 다음과 같은 규칙으로 생성한다.

```text
UUIDv7 -> Base62 처리 후 앞 12자리와 원본 파일 포맷
```

## 디렉토리 규칙

하나의 디렉토리에 너무 많은 파일이 저장되는 경우 MinIO 에 오류가 발생 할 수 있으므로 다음의 규칙에 따라 파일을 저장한다.

```text
year(4) / month / day or month
```
