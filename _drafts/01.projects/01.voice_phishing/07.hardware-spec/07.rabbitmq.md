
# RabbitMQ 하드웨어 최소 사양

> 초당 1000건, 512바이트 이하 메시지 처리 기준
> 초당 2000건, 512바이트 이하 메시지 처리 기준

## 요구 조건

| 항목        | 최소 사양                  |
| ----------- | -------------------------- |
| 메시지 크기 | 512바이트 이하             |
| 처리량      | 초당 1000건(1,000 msg/sec) |
| 메시지      | 영속화(디스크 저장) 기준   |

**최소 하드웨어 사양(권장)**  

| 항목     | 최소 사양                  |
| -------- | -------------------------- |
| CPU      | 2코어 이상 (2.0GHz+)       |
| 메모리   | 4GB RAM 이상               |
| 디스크   | SSD, 50MB/s 이상 쓰기 속도 |
|          | (최소 20GB 여유 공간)      |
| 네트워크 | 1Gbps 이더넷               |

## 요구 조건 - 2

> 초당 2,000건, 512바이트 이하 메시지 처리 기준

| 항목        | 최소 사양                   |
| ----------- | --------------------------- |
| 메시지 크기 | 512바이트 이하              |
| 처리량      | 초당 2,000건(2,000 msg/sec) |
| 메시지      | 영속화(디스크 저장) 기준    |

**최소 하드웨어 사양(권장)**  

| 항목     | 최소 사양                                  |
| -------- | ------------------------------------------ |
| CPU      | 4코어 이상 (2.5GHz+)                       |
| 메모리   | 8GB RAM 이상                               |
| 디스크   | SSD, 100MB/s 이상 쓰기 속도                |
|          | (최소 40GB 여유 공간)                      |
| 네트워크 | 1Gbps 이상(동시 연결 많으면 10Gbps도 고려) |

## 참고 사항

- 메시지 영속화가 필요 없다면 디스크 성능 요구는 낮아질 수 있음
- 클러스터, HA, 복제 등 고가용성 옵션이 필요하다면 CPU/메모리/디스크 모두 상향 필요
