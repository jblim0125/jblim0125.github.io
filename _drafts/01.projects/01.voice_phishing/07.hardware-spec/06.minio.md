# MinIO

## 전제 조건 (1Gbps 처리 기준)

| 항목              | 값                              |
| ----------------- | ------------------------------- |
| 파일 크기         | 평균 10MB 이상 (multipart 가능) |
| 암호화, 버전 관리 | 비활성화                        |

## 1Gbps (125MB/s) 기준 처리 성능 목표

| 항목              | 수치                                 |
| ----------------- | ------------------------------------ |
| 동시 처리 파일 수 | 510개 (2050MB 수준의 병렬 처리 기준) |
| 초당 요청 수      | 10~30 CPS (큰 파일 기준)             |

## 하드웨어 최소 사양 (노드 1대 기준)

| 항목   | 최소 사양                     | 설명                                                    |
| ------ | ----------------------------- | ------------------------------------------------------- |
| CPU    | 2 vCore (물리 1코어)          | Golang 기반 I/O, Erasure Coding 포함                    |
| Memory | 4 GB RAM                      | OS buffer + MinIO buffer (버퍼 I/O 적절히 설정 시 충분) |
| Disk   | SATA SSD 1~2개 (500MB/s 이상) | 병렬성 확보용으로 2개 권장                              |

> 위 스펙은 “1gbps의 단방향 처리”하는 경우에 한합니다. 양방향은 4 vCore / 8GB 이상 필요합니다.
