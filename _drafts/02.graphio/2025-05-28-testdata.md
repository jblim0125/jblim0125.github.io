# 254 서버 데이터 정리

제가 정확하게 이해하지 못하고 설명 드릴 수 있는 점 양해바랍니다.

## 오류

1. 보고서 생성 및 사용자 질의에 대해 데이터를 찾을 수 없어 발생하는 몇가지 오류
    1. 보고서 탭에서 요약 공란
    2. 보고서 탭에서 유사 사업 및 낙찰업체 목록 공란
    3. 데이터 찾을 수 없음

## 원인

1. 데이터가 없어 발생하는 오류들의 원인
    1. 자동 업데이트 - 수동 업데이트
        데이터 적재 구간과 데이터 파싱(분석) 후 적재 구간이 자동과 수동이 혼재 한 상태
        위 이유로 데이터 불일치 발생
    2. 데이터 분석(파싱) 오류
        공고 파싱 규칙을 벗어나는 경우 파싱 할 수 없음.

## 방안

1. 데이터 불일치
    1. 데이터 자동 적재 중지
    2. 5월 20일 이 후 데이터 삭제
    3. 문서 파싱 오류가 발생한 데이터(공고) 삭제 
    4. PostgreSQL 내 테이블 간 데이터 동기화(유사 사업 및 낙찰업체 목록 관련)
    5. PostgreSQL - neo4j 데이터 동기화(용역공고 리스트에서 검색 되나 PostgreSQL에 없는 데이터 관련)

## 사이드 이펙트

데이터 불일치 해소를 위해 데이터 자동 업데이트 중지 시 '메일링에서 신규 공고를 받을 수 없음'
신규 공고에 대해 메일을 받을 수 있도록 다음과 같이 변경

1. 254 서버로 인입되는 데이터를 170 서버로 변경
2. 170 서버에서 메일링 설정

170 서버 구축 당시 254 서버의 데이터 복사하였음.
구축 당시부터 현재까지 쌓인 데이터에 대해서는 마이그레이션 진행
