2.6. 질의응답
    - 질문 : 추정이라고 작성된 부분은 어떻게 도출된건가요? 
      - 추정의 경우 기사 내에서 '보인다', '예상된다'와 같은 내용을 기준으로 작성된다.
    - 질문 : 원본 데이터는 일본어 기반으로 된 기사를 기준으로 작성된건가요? 
      - 원본 기사를 한국어로 번역하여 저장하고 사용하였습니다. 
    - 질문 : 앱 결과의 경우 일본어로 작성될 수 있나요?
      - 데이터 및 프롬프트 전체를 일본어로 작성하여 기본 언어를 일본어로 설정이 가능합니다.
      - 또한, 사용자 요청(한국어, 일본어)에 따라 동작하도록 가능합니다. 
    - 질문 : 일본 기사의 번역은 어떻게 하셨나요?
      - 구글번역기 및 OCR, ChatGPT를 이용해 번역하였습니다.
    - 질문 : 유타카기연이 어떤 부품을 만들고, 부품 별 매출이 얼마이며, 혼다와의 관계는? 마더슨 그룹에 매각되기까지 시각화 및 시연이 가능한가요?
      - 유타카기연에 대해서 deepsearch 를 통해 다양한 데이터 수집이 필요
      - 텍스트와 테이블 데이터를 활용한 차트(그래프)의 경우 가능하나, 신규 이미지 생성은 아직 어려우며,
      - 인터넷과 내부 저장소에서 관련 이미지를 찾아 사용자의 사용을 유도하는 방식으로는 가능합니다.
    - 질문 : 참조문서를 실시간으로 가져온건가요?
      - 데이터를 수집하여 데이터베이스에 저장한 후 사용자 질의를 분석하여 유사 문서를 찾아 사용하도록 되어 있습니다.
    - 질문 : 유료 신문인데 어떻게 수집하였나요?
      - 사이트 가입 후 1회에 한하여 접근이 가능해 직접 수집하였습니다.
      - 추가 : 저작권 관련하여 한국의 경우 읽기, 사용에 따른 차이가 있습니다. 일본의 경우 어떤 시스템으로 이루어지는 확인이 필요하다고 봅니다.
    - 질문 : 정보의 진실 확인 방법은?(예시: 출처에 따라 사실이다 아니다를 구분하는 방법이 있을 것이고, 출력 결과에서 참고한 자료에 대한 정보를 제공할 수 있나요?)
      - 자료 수집 단계에서 출처를 필터링하여 수집하도록 설정이 가능하며, 답변 작성 시 참고 자료에 대한 정보를 제공할 수 있다.
      - 추가 : LLM에 의해 추론되어 작성되는 내용의 경우 할루시네이션이 분명 발생할 수 있고, 이 부분의 경우 사람의 경우에도 시각차에서 오는 부분이 있듯 감안되어야 할 것으로 생각합니다.(사람의 검토는 추가로 필요합니다.)
      - 또한, 화면 상 오른쪽 수정 및 미리보기 화면에서 내용 작성에 사용된 데이터의 링크 정보를 제공하여 크로스체크가 가능하도록 도울 수 있을 것 입니다.
    - 질문 : 기대하는 부분은 '전체 업무 자동화'로 전체 업무 자동화는 어렵지 않은가요?
      - 기사 2~4의 내용을 분석하여 양식에 맞춰 요약과 분석 결과를 제공하는 것은 가능합니다.
      - 다만 심층분석보고서와 같은 부분의 경우 사용자가 보고서 작성을 보다 쉽게 가능하도록 서포트 하는 수준으로 가능합니다.
