# 대전 교통공사 실증 회의

일시 : 2025.06.05

## 회의

1. 인증
   1. 대전교통공사는 keycloak 으로 인증 시스템을 구축하고 있어 인증 연동 문제 없음
2. 설치
    1. 노트북 반입 불가
    2. USB를 이용한 설치 가능
    3. 설치 시 인터넷 사용 가능하도록 제공 예정
3. 연계 데이터
   1. 내부 데이터의 경우 가능한 데이터 저장소를 1~2개 제공
   2. 외부 데이터 저장소를 기준으로
      1. 웹 기반 데이터 크롤링으로 최신 데이터가 지속적으로 수집되길 원함
      2. 1차적으로 공공데이터 포탈의 데이터를 Database Or MinIO 에 저장 후 가상화 수행
         1. 이번년도 내 기능 구현이 되길 원함
      3. 특정 사이트의 특정 데이터셋에 대해서 정의 요청 : 모비젠 to 대전교통공사
         1. 예시 사이트 : 클린아이, 공공데이터포탈 등 정보를 대전교통공사에서 제공 예정
4. 일정
   1. 실증 일정 ( 다음주까지 전달 )
