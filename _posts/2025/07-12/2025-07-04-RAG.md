## RAG란 무엇인가?

**RAG(Retrieval-Augmented Generation)**는 외부 지식 베이스에서 관련 정보를 검색한 후, 이를 바탕으로
생성형 AI 모델이 답변을 생성하는 기술입니다. 기존 LLM의 한계인 **할루시네이션(Hallucination)** 문제와
**지식 컷오프** 문제를 해결하는 핵심 기술로 주목받고 있습니다.

### RAG의 핵심 아이디어

```text
사용자 질문 → 관련 문서 검색 → 검색된 문서 + 질문 → LLM → 정확한 답변
```

### 기존 LLM과 RAG의 차이점

| 구분      | 기존 LLM           | RAG                              |
| --------- | ------------------ | -------------------------------- |
| 지식 소스 | 훈련 데이터에 고정 | 실시간 외부 데이터베이스         |
| 업데이트  | 재훈련 필요        | 데이터베이스 업데이트만으로 가능 |
| 정확성    | 할루시네이션 위험  | 검증된 소스 기반 답변            |
| 비용      | 재훈련 비용 높음   | 상대적으로 저렴한 유지보수       |

## RAG의 핵심 구성 요소

### 1. 지식 베이스 (Knowledge Base)

- **문서 컬렉션**: PDF, 웹페이지, 데이터베이스 등
- **메타데이터**: 문서 제목, 생성일, 카테고리 등
- **구조화된 데이터**: FAQ, 제품 정보, 정책 문서 등

### 2. 임베딩 모델 (Embedding Model)

- **역할**: 텍스트를 고차원 벡터로 변환
- **주요 모델들**:
  - OpenAI: `text-embedding-3-large`, `text-embedding-3-small`
  - 오픈소스: Sentence-BERT, BGE, E5
  - 다국어: Multilingual-E5, LaBSE

### 3. 벡터 데이터베이스 (Vector Database)

- **Pinecone**: 완전 관리형 벡터 DB
- **Weaviate**: 오픈소스, GraphQL 지원
- **Chroma**: 경량화, 로컬 개발에 적합
- **FAISS**: Facebook AI의 고성능 라이브러리

### 4. 생성 모델 (Generation Model)

- **GPT-4**: 고품질 답변 생성
- **Claude**: Anthropic의 헌법적 AI
- **Llama**: Meta의 오픈소스 모델

## RAG 파이프라인 상세 분석

### Phase 1: 인덱싱 (Indexing)

from langchain.text_splitter import RecursiveCharacterTextSplitter

### 2. 청킹 전략

#### 고정 크기 청킹

```python
def fixed_size_chunking(text, chunk_size=500, overlap=50):
    chunks = []
    for i in range(0, len(text), chunk_size - overlap):
        chunk = text[i:i + chunk_size]
        chunks.append(chunk)
    return chunks
```

#### 의미 기반 청킹

```python
from sentence_transformers import SentenceTransformer
import numpy as np

def semantic_chunking(sentences, similarity_threshold=0.7):
    model = SentenceTransformer('all-MiniLM-L6-v2')
    embeddings = model.encode(sentences)
    
    chunks = []
    current_chunk = [sentences[0]]
    
    for i in range(1, len(sentences)):
        similarity = np.dot(embeddings[i-1], embeddings[i])
        
        if similarity < similarity_threshold:
            chunks.append(' '.join(current_chunk))
            current_chunk = [sentences[i]]
        else:
            current_chunk.append(sentences[i])
    
    chunks.append(' '.join(current_chunk))
    return chunks
```

## 벡터 검색과 유사도 측정

### 1. 유사도 측정 방법

#### 코사인 유사도 (Cosine Similarity)

```python
import numpy as np

def cosine_similarity(vec1, vec2):
    """가장 일반적으로 사용되는 유사도 측정"""
    dot_product = np.dot(vec1, vec2)
    norm_vec1 = np.linalg.norm(vec1)
    norm_vec2 = np.linalg.norm(vec2)
    return dot_product / (norm_vec1 * norm_vec2)
```

#### 유클리드 거리 (Euclidean Distance)

```python
def euclidean_distance(vec1, vec2):
    """벡터 간 직선 거리"""
    return np.linalg.norm(vec1 - vec2)
```

#### 내적 (Dot Product)

```python
def dot_product_similarity(vec1, vec2):
    """계산이 빠르지만 벡터 크기에 영향받음"""
    return np.dot(vec1, vec2)
```

### 2. 고급 검색 전략

#### MMR (Maximal Marginal Relevance)

```python
def mmr_search(query_embedding, documents, embeddings, k=5, lambda_param=0.7):
    """다양성과 관련성의 균형을 맞춘 검색"""
    similarities = [cosine_similarity(query_embedding, emb) for emb in embeddings]
    selected = []
    selected_embeddings = []
    
    # 첫 번째 문서는 가장 유사한 것 선택
    max_idx = np.argmax(similarities)
    selected.append(documents[max_idx])
    selected_embeddings.append(embeddings[max_idx])
    
    for _ in range(k - 1):
        mmr_scores = []
        for i, doc_emb in enumerate(embeddings):
            if i in [documents.index(doc) for doc in selected]:
                mmr_scores.append(-float('inf'))
                continue
                
            relevance = similarities[i]
            max_sim_to_selected = max([
                cosine_similarity(doc_emb, sel_emb) 
                for sel_emb in selected_embeddings
            ])
            
            mmr_score = lambda_param * relevance - (1 - lambda_param) * max_sim_to_selected
            mmr_scores.append(mmr_score)
        
        max_mmr_idx = np.argmax(mmr_scores)
        selected.append(documents[max_mmr_idx])
        selected_embeddings.append(embeddings[max_mmr_idx])
    
    return selected
```

## 랭킹과 리랭킹 전략

### 1. 초기 랭킹 (First-stage Ranking)

벡터 검색에서 초기 후보군을 선별하는 단계입니다.

```python
class InitialRanker:
    def __init__(self, vectorstore, top_k=20):
        self.vectorstore = vectorstore
        self.top_k = top_k
    
    def rank(self, query):
        # 벡터 유사도 기반 초기 검색
        results = self.vectorstore.similarity_search_with_score(
            query, 
            k=self.top_k
        )
        
        # 점수 정규화
        if results:
            max_score = max(score for _, score in results)
            normalized_results = [
                (doc, score / max_score) for doc, score in results
            ]
            return normalized_results
        
        return []
```

### 2. 리랭킹 (Re-ranking)

더 정확한 관련성 평가를 위한 두 번째 단계입니다.

#### Cross-Encoder 기반 리랭킹

```python
from sentence_transformers import CrossEncoder

class CrossEncoderReranker:
    def __init__(self, model_name='cross-encoder/ms-marco-MiniLM-L-12-v2'):
        self.model = CrossEncoder(model_name)
    
    def rerank(self, query, documents, top_k=5):
        # 쿼리-문서 쌍 생성
        pairs = [[query, doc.page_content] for doc in documents]
        
        # 관련성 점수 예측
        scores = self.model.predict(pairs)
        
        # 점수 기준 정렬
        ranked_docs = sorted(
            zip(documents, scores), 
            key=lambda x: x[1], 
            reverse=True
        )
        
        return ranked_docs[:top_k]
```

## 실전 RAG 구현

### 완전한 RAG 시스템 구축

```python
import os
from typing import List, Dict, Any
from langchain.document_loaders import PyPDFLoader, TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Chroma
from langchain.llms import OpenAI
from langchain.chains import RetrievalQA
from langchain.prompts import PromptTemplate

class AdvancedRAGSystem:
    def __init__(self, documents_path: str, persist_directory: str = "./chroma_db"):
        self.documents_path = documents_path
        self.persist_directory = persist_directory
        self.embeddings = OpenAIEmbeddings(model="text-embedding-3-large")
        self.llm = OpenAI(temperature=0, model_name="gpt-4")
        self.vectorstore = None
        self.qa_chain = None
        
    def load_documents(self) -> List[Any]:
        """다양한 형식의 문서 로딩"""
        documents = []
        
        for root, dirs, files in os.walk(self.documents_path):
            for file in files:
                file_path = os.path.join(root, file)
                
                if file.endswith('.pdf'):
                    loader = PyPDFLoader(file_path)
                elif file.endswith('.txt'):
                    loader = TextLoader(file_path)
                else:
                    continue
                
                docs = loader.load()
                documents.extend(docs)
        
        return documents
    
    def preprocess_documents(self, documents: List[Any]) -> List[Any]:
        """문서 전처리 및 청킹"""
        text_splitter = RecursiveCharacterTextSplitter(
            chunk_size=1000,
            chunk_overlap=200,
            separators=["\n\n", "\n", ". ", " ", ""],
            length_function=len
        )
        
        chunks = text_splitter.split_documents(documents)
        
        # 메타데이터 강화
        for chunk in chunks:
            chunk.metadata.update({
                'chunk_size': len(chunk.page_content),
                'created_at': '2025-07-04'
            })
        
        return chunks
    
    def build_vectorstore(self, force_rebuild: bool = False):
        """벡터 저장소 구축"""
        if os.path.exists(self.persist_directory) and not force_rebuild:
            self.vectorstore = Chroma(
                persist_directory=self.persist_directory,
                embedding_function=self.embeddings
            )
            print("기존 벡터 저장소를 로딩했습니다.")
        else:
            print("문서를 로딩하고 벡터 저장소를 구축합니다...")
            documents = self.load_documents()
            chunks = self.preprocess_documents(documents)
            
            self.vectorstore = Chroma.from_documents(
                documents=chunks,
                embedding=self.embeddings,
                persist_directory=self.persist_directory
            )
            print(f"총 {len(chunks)}개의 청크로 벡터 저장소를 구축했습니다.")
    
    def query(self, question: str) -> Dict[str, Any]:
        """질문에 대한 답변 생성"""
        if self.qa_chain is None:
            raise ValueError("QA 체인이 초기화되지 않았습니다.")
        
        result = self.qa_chain({"query": question})
        
        return {
            "answer": result["result"],
            "source_documents": [
                {
                    "content": doc.page_content,
                    "metadata": doc.metadata
                }
                for doc in result["source_documents"]
            ]
        }
```

## RAG 성능 최적화

### 1. 평가 메트릭

```python
from typing import List, Tuple
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

class RAGEvaluator:
    def __init__(self):
        self.embedding_model = OpenAIEmbeddings()
    
    def calculate_retrieval_precision_recall(
        self, 
        retrieved_docs: List[str], 
        relevant_docs: List[str]
    ) -> Tuple[float, float]:
        """검색 정확도와 재현율 계산"""
        retrieved_set = set(retrieved_docs)
        relevant_set = set(relevant_docs)
        
        true_positives = len(retrieved_set.intersection(relevant_set))
        
        precision = true_positives / len(retrieved_set) if retrieved_set else 0
        recall = true_positives / len(relevant_set) if relevant_set else 0
        
        return precision, recall
    
    def calculate_answer_similarity(
        self, 
        generated_answer: str, 
        reference_answer: str
    ) -> float:
        """생성된 답변과 참조 답변의 유사도 계산"""
        gen_embedding = self.embedding_model.embed_query(generated_answer)
        ref_embedding = self.embedding_model.embed_query(reference_answer)
        
        similarity = cosine_similarity([gen_embedding], [ref_embedding])[0][0]
        return similarity
```

### 2. 캐싱 전략

```python
import hashlib
import json
import time
from typing import Optional

class RAGCache:
    def __init__(self, cache_ttl: int = 3600):  # 1시간 TTL
        self.cache = {}
        self.cache_ttl = cache_ttl
    
    def _generate_cache_key(self, query: str, config: dict) -> str:
        """쿼리와 설정을 기반으로 캐시 키 생성"""
        cache_data = {
            'query': query.lower().strip(),
            'config': config
        }
        cache_string = json.dumps(cache_data, sort_keys=True)
        return hashlib.md5(cache_string.encode()).hexdigest()
    
    def get(self, query: str, config: dict) -> Optional[dict]:
        """캐시에서 결과 조회"""
        cache_key = self._generate_cache_key(query, config)
        
        if cache_key in self.cache:
            cached_result, timestamp = self.cache[cache_key]
            
            # TTL 확인
            if time.time() - timestamp < self.cache_ttl:
                return cached_result
            else:
                # 만료된 캐시 삭제
                del self.cache[cache_key]
        
        return None
    
    def set(self, query: str, config: dict, result: dict):
        """결과를 캐시에 저장"""
        cache_key = self._generate_cache_key(query, config)
        self.cache[cache_key] = (result, time.time())
```

## 결론 및 향후 발전 방향

### RAG의 현재 상태

RAG는 현재 AI 산업에서 가장 중요한 기술 중 하나로 자리잡았습니다. 특히 다음과 같은 영역에서 큰 성과를 보이고 있습니다:

1. **기업 내부 문서 검색**: 사내 지식베이스 활용
2. **고객 서비스**: FAQ 및 문서 기반 자동 응답
3. **연구 지원**: 논문 및 기술 문서 분석
4. **법률/의료**: 전문 도메인 지식 활용

### 마무리

RAG는 단순한 검색-생성 파이프라인을 넘어서 지능적인 지식 활용 시스템으로 발전하고 있습니다.

**핵심 포인트 요약:**

1. **정확한 청킹**: 문서의 의미를 보존하는 분할 전략
2. **고품질 임베딩**: 도메인 특화 모델 선택
3. **효과적인 검색**: 하이브리드 검색과 리랭킹 활용
4. **지속적인 평가**: 성능 모니터링과 개선
5. **사용자 경험**: 빠른 응답과 투명한 소스 제공

RAG를 성공적으로 구현하기 위해서는 기술적 구현뿐만 아니라 도메인 지식, 사용자 요구사항, 그리고 지속적인 개선이 필요합니다. 

이 가이드가 RAG 시스템을 구축하고 최적화하는 데 도움이 되기를 바랍니다!
